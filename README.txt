RailExploreIndia.in — Open Rails Activities website
Files:
- index.html: website
- styles.css: responsive styling
- script.js: search, filters, cards and demo actions
- hero-reference.png: generated visual used as the homepage hero background

To run locally: open index.html in a modern browser.
For production: upload these files to your web host and replace the demo download/upload/community actions with your real backend/storage links.
